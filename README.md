# Pride Estates

Pride Estates is a real estate builder that sells flats in apartment buildings and lets customers pay for them in easy monthly installments over several years, instead of one lump sum.

This project is the online system that runs that business. It has three parts:

## 1. A public website

A modern, attractive website where anyone can browse the builder's projects (starting with the first one, "Dummy Pride"), see the different flat types and their prices, understand how the installment plans work, check how many flats are still available, and get in touch to book a flat.

## 2. An admin panel

A private dashboard for the builder's office staff. From here, the team can add new projects and flats, create and manage customer bookings, set up payment plans, record payments as they come in, and see a list of customers who are late on a payment so they can follow up.

## 3. A customer panel

A private, read-only account for each buyer. After logging in, a customer can see their flat details, how much they've paid so far, how much is left, when their next payment is due, and their full payment history.

## Where things stand

This system is being built step by step, with each part tested before moving to the next. At this stage, logins and roles, the projects/flats setup, and the admin's project management screens are working. The booking process, payment tracking, reminders, and the public website are being built next.

---

This is a private, in-development project for Pride Estates and is not yet open for public use.
